# AI 聊天 `/` 命令联想 — 设计说明

**日期**：2026-08-06  
**状态**：已批准（用户选 A：Tab/Enter 填入不发送）

## 目标

输入以 `/` 开头时，在输入框上方弹出当前支持的斜杠命令列表，每行「命令名 + 同行简介」，交互类似 Claude Code。

## 交互（方案 A）

| 操作 | 行为 |
|------|------|
| 输入 `/` 或 `/前缀` | 过滤并显示匹配命令 |
| ↑↓ | 高亮切换 |
| Tab / Enter | 填入输入框，**不**发送 |
| Esc | 关闭面板，保留输入 |
| 点击行 | 同 Tab |
| 再按 Enter | 走现有发送/执行逻辑 |
| 含空格或换行 | 关闭联想（已离开命令名阶段） |
| 选号模式下纯数字 | 不弹面板 |

选号模式（`/resume` 后）仅联想：`/cancel`、`/resume`、`/sessions`。

## 命令表

| 命令 | 简介 | 可见性 |
|------|------|--------|
| `/resume` | 列出历史会话，按编号恢复 | 始终 |
| `/sessions` | 同 `/resume` | 始终 |
| `/new` | 新建空会话（先保存当前） | 非选号 |
| `/danger` | 本会话开启危险模式 | 非选号 |
| `/safe` | 关闭危险模式 | 非选号 |
| `/cancel` | 取消 `/resume` 选号 | 仅选号 |

## 实现落点

- `src/lib/slashCommands.ts`：元数据 + 过滤
- `ChatPanel.svelte`：面板 UI + 键盘；Esc 关面板优先于 Esc×2 取消选号

## 非目标

- 不为 PowerShell 模块命令（`gs`/`gg`）做联想
- 不新增 slash 命令语义，仅发现性增强
